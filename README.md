# Electronic-Circuits--Zener-Regulator
## AIM:
To implement a Zener Voltage regulator and to obtain the output for variable loads and variable input voltages.
## APPARATUS REQUIRED:
1. Regulated Power Supply(0-30)V
2. Zener Diode 1N4732
3. Decade Resistance Box
4. Bread Board
5. DC Ammeter (0-200)mA
6. DC Voltmeter (0-30)V

## PROCEDURE:
1.	Connections are made as shown in the circuit diagram.
   
2.	Initial reading is taken at origin, with load resistance at 1kΩ and the input voltage is increased till Zener diode breaks down.
   
3.	At the point where Zener diode just breaks down, the voltmeter and ammeter readings are noted down.
   
4.	With the load resistor at 1kΩ input voltage is increased and the readings of the voltmeter and ammeter are noted down.
   This is done to verify that the output voltage remains a constant even when the input voltage changes.

5.	Next the input voltage is set at 8V and the load resistance is increased in steps of 200Ω, and the corresponding ammeter and voltmeter readings are noted down.
   
6.	This is done to verify that the output voltage remains a constant irrespective of change in the load.
